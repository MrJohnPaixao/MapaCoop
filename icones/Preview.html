Instalar em 3 passos

Copie a pasta

Jogue pwa/icons/, MapaCoop-icon.svg e manifest.json para a raiz pública do seu app.

Ligue o manifest

Adicione as tags abaixo no <head>. O theme-color deixa a barra do sistema no Deep Space.

Pronto p/ instalar

Em HTTPS + service worker, o navegador oferece "Adicionar à tela inicial" com este ícone.

<head> — cole no seu HTML
<!-- PWA · MapaCoop -->
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#0A0F1E">
<link rel="icon" type="image/svg+xml" href="/MapaCoop-icon.svg">
<link rel="icon" type="image/png" sizes="32x32" href="/icons/favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/icons/favicon-16.png">
<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png">
